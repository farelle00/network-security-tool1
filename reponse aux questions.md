Question 1 : Quelle est la différence entre git add et git commit ?

La commande git add permet de préparer les fichiers modifiés dans la zone de staging (zone de préparation). 
La commande git commit enregistre les modifications préparées dans l’historique du dépôt Git.

Question 2 : Que représente un commit dans Git ?
Un commit représente un instantané des modifications enregistrées dans le dépôt à un moment donné. 
Il conserve un état du projet dans l’historique Git et comporte un identifiant ainsi qu’un message descriptif.

Question 3 : Pourquoi créer une branche plutôt que modifier directement la branche principale ?
Une branche permet de développer une fonctionnalité séparément de la branche principale. 
Cela permet de travailler et de tester les changements indépendamment, puis de les examiner avant de les intégrer à la branche principale.

Question 4 : Quel est le rôle d’une Pull Request dans un projet collaboratif ?
Une Pull Request permet de proposer des modifications d’une branche vers une autre, afin qu’elles puissent être examinées avant leur fusion. 
Elle facilite la revue du code et la collaboration entre les membres d’une équipe.
